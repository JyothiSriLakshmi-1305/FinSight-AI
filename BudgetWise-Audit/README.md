# 🚀 Overview

BudgetWise is an AI-powered expense forecasting web application designed to help users manage their finances intelligently.

Unlike traditional budgeting tools, BudgetWise provides **real-time expense predictions, affordability analysis, AI-driven recommendations, and financial insights** to support better budgeting and spending decisions.

---

# ❗ Problem Statement

Managing personal finances can be difficult due to:

- 💸 Unpredictable expenses (medical emergencies, repairs, etc.)
- 📉 Income volatility (freelancers, variable income)
- 📊 Traditional budgeting tools that are static and non-adaptive

These challenges make it difficult to effectively plan, monitor, and control personal expenses.

---

# 💡 Solution

BudgetWise transforms traditional budgeting into an intelligent financial assistant by:

- 📊 Providing real-time expense forecasting
- 💰 Performing instant affordability analysis
- 🤖 Delivering AI-powered spending recommendations
- 💬 Assisting users through an AI chatbot

The platform enables users to make informed financial decisions based on predictive analytics.

# 🧠 AI/ML Model

### Algorithm

**Random Forest**

### Training Dataset

The model is trained using a custom dataset containing:

- Budget allocations
- Monthly expenses
- Product costs
- Financial spending records

### Model Capabilities

- Predict future expenses
- Analyze spending behavior
- Generate personalized financial insights
- Improve budgeting decisions
